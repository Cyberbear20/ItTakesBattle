# Duell der Zwei

Eine live synchronisierte 15-Runden-Minispiel-Olympiade für **It Takes Two**.

## Spielen

1. GitHub-Pages-Link öffnen.
2. **Raum eröffnen** wählen.
3. Den Einladungslink an den Mitspieler schicken.
4. Namen eintragen, Lostopf anpassen und 15 Spiele auslosen.

Der Gastgeber lässt seinen Browser-Tab während des Duells geöffnet. Der Spielstand wird dort zusätzlich lokal gespeichert.
